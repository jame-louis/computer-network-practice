## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| ICMP协议 | 网络层的控制协议，ping和tracert基于ICMP工作 | 像打电话时的"喂，能听到吗？""能！" |
| TTL | 数据包生存时间，每经过一个路由器减1，到0被丢弃 | 像快递的"中转次数上限" |
| ARP缓存 | IP地址→MAC地址的动态映射表 | 像通讯录，先打电话才能存入号码 |
| DNS解析 | 域名→IP地址的转换 | 像电话台查号码，报名字给你号码 |
| DHCP | 自动分配IP地址的协议 | 像前台自动发房卡 |

### 关键命令速查

```
ping <目标>          ← 测试连通性
ping -t <目标>       ← 一直ping，Ctrl+C停止
ping -n 10 <目标>    ← 只ping 10次
ipconfig             ← 查看IP/掩码/网关
ipconfig /all        ← 完整信息：MAC/DNS/DHCP
ipconfig /release    ← 释放IP地址
ipconfig /renew      ← 重新获取IP地址
arp -a               ← 查看ARP缓存
tracert <目标>       ← 跟踪路由路径
tracert -d <目标>    ← 跟踪路由（不解析域名，更快）
nslookup <域名>      ← 查询DNS解析
```

## 三、实验任务

### 🔵 基础任务（必做，约30分钟）

**任务1：ping五步连通性检测**

依次执行以下命令，记录每次结果（是否通？TTL值？往返时间？）：

```
ping 127.0.0.1
ping <本机IP>
ping <网关IP>
ping 8.8.8.8
ping www.baidu.com
```

**规则：** 哪一步开始不通，故障就出在哪一步之前。

**任务2：查看本机网络配置**

执行 `ipconfig /all`，记录以下信息：
- IP地址、子网掩码、默认网关
- DNS服务器地址
- 物理地址（MAC）
- 判断：你的IP是DHCP自动获取还是静态配置的？

**任务3：查看ARP缓存**

```
ping <网关IP>
arp -a
```

观察：ping网关之后，arp -a是否出现了网关的MAC地址？

### 🟡 进阶任务（选做，约25分钟）

**任务4：跟踪路由路径**

```
tracert www.baidu.com
tracert -d www.163.com
```

- 记录经过了多少跳
- 比较带`-d`和不带的速度差异
- 分析：`* * *` 出现在哪些跳点？可能是什么原因？

**任务5：DNS解析测试**

```
nslookup www.baidu.com
```

然后进入交互模式查询MX记录：
```
nslookup
> set type=mx
> google.com
```

思考：DNS不只解析域名到IP，还能查什么？

### 🔴 挑战任务（选做，约15分钟）

**任务6：网络故障诊断实战**

场景：你的电脑突然不能上网了。用今天学到的命令，按照正确的检测次序排查，写出排查步骤和每一步的判断依据。

**提示：** 使用ping五步法（127.0.0.1→本机IP→网关→远程IP→域名），每步判断什么？

## 四、思考题

1. 你的计算机平时能正常上网，某天突然不能上网了，你能否查出是什么原因造成的？
2. 如何查出计算机的MAC地址？有多少种方法？
3. 在同一个局域网内，知道对方的IP地址，如何查出它的主机名？
