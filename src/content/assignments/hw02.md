## 二、背景知识

### 核心概念

| 概念 | 含义 | 类比 |
|---|---|---|
| 子网掩码 | 区分IP地址中网络位和主机位的"尺子" | 门牌号中的"小区名"和"房间号"分界线 |
| 网络地址 | 子网的起始地址，主机位全0 | 公交车首站（不能分配给主机） |
| 广播地址 | 子网的结束地址，主机位全1 | 公交车末站（不能分配给主机） |
| 可用主机范围 | 网络地址和广播地址之间的地址 | 公交车中间站（可以分配） |
| 网关 | 路由器近端接口IP，跨子网通信的"关口" | 楼栋大门，出门才能去别栋 |
| FLSM | 固定长度子网掩码，所有子网大小相同 | 一栋楼分相同户型 |
| VLSM | 可变长度子网掩码，按需分配不同大小 | 公司分办公室：大部门大房间 |

### 关键计算公式

```
子网数 = 2ⁿ          （n = 从主机位借的位数）
主机数 = 2ʰ - 2      （h = 剩余主机位数，减2是去掉网络地址和广播地址）
子网间隔 = 256 - 掩码最后字节值

网络地址 = IP地址 AND 子网掩码
广播地址 = 网络地址 + 子网间隔 - 1
可用范围 = 网络地址+1  ~  广播地址-1
```

### 8421速算法（二进制↔十进制转换）

```
位权:  128   64   32   16    8    4    2    1
位号:   7    6    5    4    3    2    1    0

例：10100000 = 128 + 32 = 160
例：224 = 128 + 64 + 32 = 11100000
```

## 五、Packet Tracer 操作指引

> 如果你是第一次使用Packet Tracer，请按照以下步骤操作。

### 5.1 界面认识

| 区域 | 名称 | 作用 |
|---|---|---|
| 左下方 | 设备类型库 | 选择设备类别（路由器/交换机/终端设备/线缆等） |
| 左下方 | 特定设备库 | 选择具体型号（如交换机→2960） |
| 工作区 | 拓扑搭建区 | 拖放设备、连线、查看状态 |
| 顶部 | 常用工具栏 | 选择/删除/标签/添加数据包等 |
| 右下角 | 实时/模拟模式 | 默认"实时"模式，可直接ping测试 |

### 5.2 搭建拓扑步骤

**添加交换机：**
1. 在设备类型库中单击 `Switches`
2. 在特定设备库中找到 `2960`（24口交换机）
3. 拖到工作区

**添加PC：**
1. 在设备类型库中单击 `End Devices`
2. 在特定设备库中找到 `PC-PT`
3. 连续拖4台到工作区

**连线（直通线）：**
1. 在设备类型库中单击 `Connections`
2. 选择 `Copper Straight-Through`（直通线，第一个图标）
3. 单击PC → 选择 `FastEthernet`
4. 单击交换机 → 选择空闲的 `FastEthernet` 接口

> **提示：** 不确定用什么线时，可用 `Automatically Choose Connection Type`（自动连接），让软件自动选择。

### 5.3 配置IP地址

1. 单击PC → 弹出设备配置窗口
2. 选择 `Desktop` 选项卡
3. 单击 `IP Configuration`
4. 填写：
   - **IP Address：** 根据子网划分表填写
   - **Subnet Mask：** 255.255.255.224（本实验）
   - **Default Gateway：** 留空（本实验不需要路由器）
5. 关闭窗口（配置自动保存）

### 5.4 使用ping验证

1. 单击PC → `Desktop` → `Command Prompt`
2. 输入命令：`ping <目标IP地址>`
3. 观察结果：
   - `Reply from ...` = 通 ✅
   - `Request timed out.` = 不通 ❌

### 5.5 常见问题

| 问题 | 原因 | 解决方法 |
|---|---|---|
| 连线后接口指示灯不是绿色 | 未正确连接 | 删除线缆重新连接，确认选择直通线 |
| PC配置面板没有IP Configuration | 选错设备类型 | 确认是PC-PT（不是Generic或Server-PT） |
| ping不通同子网PC | IP/掩码配置错误 | 检查：①IP是否在可用范围 ②掩码是否一致 |
| ping不同子网也通了 | 掩码设置小了 | 检查掩码是否设为/27 |
